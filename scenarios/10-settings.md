# 场景十：设置中心页面（个人配置 / 系统偏好）

> **创建时间**：2026-11-25\
> **最后修改时间**：2026-11-27\
> **当前版本**：V\_1.2\
> **适用对象**：AI 编码助手、开发团队\

### 10.1 场景描述

设置中心是**低频访问、以偏好配置为主**的聚合页：左侧分类导航 + 右侧单页长滚动分区，用户点开一项偏好就地修改，最后统一保存。与 CRUD 场景（§1–§8）和工作台（§9）的区别：

| 维度 | CRUD 页（场景一~八） | 工作台（场景九） | 设置中心（本场景） |
| --- | --- | --- | --- |
| 主体结构 | 一张 DataGrid 主表 | 多块指标/待办卡片 | 分类导航 + 单页长滚动分区 |
| 用户动作 | 查询 / 增删改查 | 看一眼 → 跳走或就地办结 | 切开关/选偏好 → 统一保存 |
| 数据写入 | 每个操作即时提交 | 少量就地办结 | **顶条唯一保存按钮一次提交全部分区** |
| 保存留痕 | 各业务表自理 | 不涉及 | 变更记录表格（声明式自动刷新） |

**三个核心建议**：

1. **分区即语义**：每个分区（资料与偏好 / 安全与登录 / 通知偏好 / 外观与语言 / 操作日志）一个分区头 + 若干独立 wd-panel；分区头 = tint 图标色块 + 标题 + 灰色描述，根节点带 `id`（`sec-{key}`）供导航锚点定位。
2. **统一保存 + 自动留痕**：顶条**唯一**「保存更改」按钮（wd-api-button）经 `:api-param` 汇总全部分区状态提交，配 `head-refresh-datagrid="settings-logs"` 声明式自动刷新变更记录表格——零手写刷新代码。
3. **确认机制分级**：强制下线（可逆、中风险）用 wd-popconfirm-button；注销账号（不可恢复）必须用 wd-prompt-button 强确认，确认文案写明后果与不可逆（§0.9），禁止降级为气泡确认。当前 PromptButton **不校验输入内容**（源码 ElMessageBox.prompt 未暴露校验配置），仅作强确认交互；「输入指定文本后才允许确认」需组件规格扩展（见 [99-spec-requests.md](99-spec-requests.md)）。

### 10.3 布局骨架与滚动定位

```css
/* 页面根容器：只做布局，不加背景色、边框、额外内边距（§0.3 布局容器豁免） */
.settings-page {
  display: flex; flex-direction: column; height: 100%;
  max-width: 1280px; margin: 0 auto;
}

/* 主体两栏：左导航定宽，右内容区独立滚动 */
.settings-body {
  display: grid; grid-template-columns: 236px 1fr;
  gap: 12px; align-items: start;
}

/* 仅设置区滚动：顶条与左导航固定，右内容区 overflow-y:auto */
.settings-content { overflow-y: auto; }
```

**滚动定位要点**：

- 分类点击用**容器级** `scrollTo({ top, behavior: 'smooth' })` 平滑定位到对应分区（按 `sec-{key}` 的 `offsetTop` 换算）；
- 高亮监听**该容器**的 scroll 事件（页面 `scrollTop` 保持不变），按滚动位置反算当前分区并高亮导航项；
- `≤1100px` 两栏降单列，回退整页滚动，滚动高亮允许降级；
- 组件卸载时移除 scroll 监听，防内存泄漏。

### 10.4 面板样式约定（与工作台相反）

> **设置页 wd-panel 保持原生样式，禁止 `:deep()` 覆写。** 与工作台的紧凑化（§9.3 压 header/body 内边距）相反：设置页访问频率低、阅读优先，保留面板原生留白与外边距，换肤令牌全量跟随。纵向节奏依赖 wd-panel 原生 margin-bottom，分区之间额外留 22px。

面板标题行只保留 `title` + `description`，**不传 icon prop**；图标只出现在分区头 tint 色块与左侧导航色块（28-30px 圆角色块，底色用 `--el-color-primary-light-9` 等 tint 变量）。

### 10.5 偏好控件选型

| 控件形态 | 适用 | 实现 |
| --- | --- | --- |
| 开关行 | 布尔偏好（通知开关、隐身模式等） | 左侧主文案 + 12px 灰色说明，右侧 `wd-switch`；行间用分隔或间距（§0.3 面板内元素分隔） |
| 按钮组单选 | 选项 ≤3 且文案短（主题、语言） | `wd-radio-list` 开 `:button-style`（§0.6 少选项按钮形态），不用 select |
| 下拉选择 | 选项文案长（时区） | `wd-select`（§0.6 口径：文案长不适合按钮形态） |
| 按钮组多选 | 兴趣/渠道类，选项 ≤6 且文案短 | `wd-checkbox-list` 静态 data-source + `:button-style` |
| 开关联动 | 开关控制另一控件可用性 | 开关关闭时联动控件 `disabled`（如免打扰开关 → 时间范围选择器禁用） |
| 业务关联选择 | 选人/选设备等业务实体 | 弹窗选择器（场景六），不用裸 select |

### 10.6 统一保存与变更留痕（声明式联动）

```
用户修改任意分区偏好（仅改本地状态，不逐项提交）
      ↓
点击顶条唯一「保存更改」按钮（wd-api-button）
   :api-param 汇总全部分区状态 → POST /settings/save
      ↓
head-refresh-datagrid="settings-logs" 声明式联动
      ↓
变更记录表格（wd-data-grid，filter="settings-logs"）自动刷新，零手写刷新代码
```

要点：

- **分区状态本地暂存**，不逐项即时提交——避免频繁请求与"改一半"状态落库；离开前由顶部 tips 提醒「离开前记得保存更改」。
- 保存按钮**全页唯一**，放在顶条右侧（用户无需滚到分区里找保存）；分区内部不放各自的保存按钮。
- 变更记录表格列 = ID / 变更区块 / 操作说明 / 时间；登录记录表格列 = 时间 / 设备 / IP；**表格内 tag 一律 `size="small"`**；短状态（登录结果）**不单独占列**，与设备名合并展示（设备名后跟 success/danger tag）。
- 表格按只读展示配置：`:tools="{ refresh: true }"`、`:with-index="false"`、`:with-pager="false"`。

### 10.7 危险操作与确认分级

| 风险等级 | 典型操作 | 确认方式 | 文案要求 |
| --- | --- | --- | --- |
| 可逆、中风险 | 强制下线其他设备 | `wd-popconfirm-button` 气泡确认 | 写明影响范围（「将下线除当前设备外的 N 台设备」） |
| 不可恢复、高危 | 注销账号 | `wd-prompt-button`（type="danger"）强确认 | 写明后果与不可逆（如「注销后数据无法恢复，请谨慎操作」）；当前 PromptButton 不校验输入内容，仅作强确认交互，「输入指定文本后才允许确认」需组件规格扩展（见 [99-spec-requests.md](99-spec-requests.md)）；禁止降级为 popconfirm |
| 常规操作 | 保存偏好、普通开关 | 无需确认，直接提交 | — |

危险操作独立成 panel（顶部 `wd-tips type="box"` 警示条（icon="WarningFilled"、bg-type="auto" 自动警告橙浅底）+ 一行危险操作项：主文案 + 说明 + 右侧确认按钮），与普通偏好分区视觉隔离。

### 10.8 规范要点

| 项 | 规范 |
| --- | --- |
| 适用判定 | 左侧分类导航 + 右侧长滚动分区、以开关/单选偏好为主、统一保存留痕的配置页用本场景；出现"完整记录列表 + 分页 + 增删改"改用 §1 / §8 |
| 页面容器 | 根容器只做布局（flex 纵向 / 双栏 grid、max-width 1280px 居中），不加背景色、边框、额外内边距（§0.3 布局容器豁免） |
| 页面介绍 | 顶部 `wd-tips type="box"` 说明保存机制与注意事项（§0.1，设置中心不豁免） |
| 面板样式 | 所有区块一律 wd-panel 且**保持原生样式，禁止 :deep 覆写**（§10.4，与 §9.3 工作台紧凑化相反） |
| 保存模型 | 顶条唯一 wd-api-button「保存更改」`:api-param` 汇总提交 + `head-refresh-datagrid` 声明式刷新变更记录表格；分区本地暂存、不放分区级保存按钮 |
| 滚动定位 | 仅右内容区滚动，分类点击容器 scrollTo 平滑定位、高亮监听容器 scroll；≤1100px 回退整页滚动；卸载移除监听 |
| 控件选型 | 按 §10.5：短文案少选项 button-style、长文案下拉、布尔开关行、业务实体走弹窗选择器（场景六） |
| 确认分级 | 按 §10.7 / §0.9：可逆中风险 popconfirm、不可恢复高危 prompt 强确认、常规不确认 |
| 表格规范 | tag `size="small"`、短状态与主列合并展示、只读配置（§10.6） |
| 状态反馈 | 保存成功 / 失败 ElMessage 反馈（§0.8）；保存失败表单态不清空 |
| 文案 | 分区头 = tint 色块 + 标题 + 灰色一行描述；说明性文字 12px 灰色；其余遵守 §0.12 |

### 10.9 该场景对组件规格的补充需求

| 组件 | 补充项 | 说明 |
| --- | --- | --- |
| — | — | 设置中心全部由既有能力组合实现（wd-panel / wd-switch / wd-radio-list / wd-select / wd-checkbox-list / wd-date-range-picker / wd-api-button / wd-popconfirm-button / wd-prompt-button / wd-data-grid / wd-tips / wd-tag），不新增组件规格 |

> 结论：场景十**不新增组件规格**。
